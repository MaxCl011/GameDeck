##Specifications
-4GB Raspberry pi CM4
-Custom Carrier Board
-7 Inch IPS LCD Display
-2x 3.7V 5000mAh LiPo
-Custom Power Board
-Custom 3D Printed Chassis with brass heat set inserts

##Bill of Materials (BOM)

##Core Computing
  -Raspberry pi CM4 Lite (4GB Ram, Wifi) *Core processor and memory
  -Custom KiCad Carrier PCB *Custom board Routing CM4 signals to top edge ports
  -Standalone IP5306 Power Daughterboard *Manages Battery Charging, 5.1V/3A boost regulations and system power

##Display and visuals
  -7 inch 1024x600 IPS HDMI Display Module *Flush mounted main screen driven via short internal HDMI connection

##Power and Battery Managment
  -2x 3.7V 5000mAh 1S LiPo Cells *Wired in parallel (1S2P) for 10,000mAh total capacity
  -1S PCM Protection Board (DW01A + 8205A) *Over charge, over discharge, and short circut safety
  -Top edge USB-C Charging Port *Mounted on top edge for charging and power input
  -SPDT Slide Switch *Physical power switch wired to the IP5306 enable pin

##Controls and Hardware
  -2x PSP-Style 2-Axis Analog Slide Joysticks *Low profile thumbsticks for navigation
  -Tactile Switch Matrix & Button Caps *D-Pad, ABXY buttons, start/scelect, and L/R sholder triggers
  -M2.5 Heat-Set Brass Inserts & Screws *Securing internal components and boards
